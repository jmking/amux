# Agent world models

USDZ files loaded by `WorldAssets`. Each is converted from a CC0 (public domain)
low-poly pack by `macos/Assets/convert.py`; the sources and their licence
evidence are recorded in `macos/Assets/work/catalog/selection.json`. Anything
missing here falls back to a primitive stand-in from `WorldPrimitives`, so the
scene runs with or without this folder's contents.
